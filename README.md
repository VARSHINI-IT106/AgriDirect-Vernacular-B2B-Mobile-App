# AgriDirect – Vernacular B2B Mobile App

## 📌 Project Overview

AgriDirect is a mobile UI/UX design concept created to help rural farmers connect directly with verified buyers.

The application focuses on simple navigation, accessibility, and a farmer-friendly interface.

## 🎯 Objective

- Help farmers list their crops easily
- Display crop quantity and pricing clearly
- Connect farmers with buyers
- Manage orders in a simple interface
- Provide a clean and accessible mobile experience

## ✨ Key Features

- Farmer-friendly dashboard
- Add and manage crops
- Crop details and availability
- Buyer order management
- Order confirmation flow
- Farmer profile management
- Simple and accessible navigation

## 🎨 UI/UX Design

**Tool:** Figma

**Design Focus:**
- Simple navigation
- Clean mobile interface
- Accessibility
- Vernacular/local-user friendly experience
- Consistent colors and components
